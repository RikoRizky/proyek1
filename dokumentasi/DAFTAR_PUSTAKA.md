# DAFTAR PUSTAKA

Berikut adalah daftar referensi akademis, dokumentasi teknis, dan pustaka yang digunakan sebagai acuan perancangan serta implementasi sistem **SiLADATA (Sistem Layanan Dokumen Akreditasi)**:

1. **Badan Akreditasi Nasional Perguruan Tinggi (BAN-PT).** (2019). *Peraturan BAN-PT Nomor 2 Tahun 2019 tentang Panduan Penyusunan Laporan Evaluasi Diri (LED) dan Laporan Kinerja Program Studi (LKPS) dalam Instrumen Akreditasi Program Studi (IAPS) 4.0*. Jakarta: BAN-PT.
2. **Fowler, M.** (2002). *Patterns of Enterprise Application Architecture*. Boston: Addison-Wesley Longman Publishing Co., Inc. *(Digunakan sebagai acuan teoretis pola arsitektur Model-View-Controller dan Data Mapper/Active Record)*.
3. **Stauffer, M.** (2019). *Laravel: Up & Running: A Framework for Building Modern PHP Apps (2nd Edition)*. Sebastopol: O'Reilly Media. *(Digunakan sebagai referensi teknis implementasi framework Laravel, MVC, dan Blade Templating)*.
4. **Sommerville, I.** (2015). *Software Engineering (10th Edition)*. Boston: Pearson. *(Digunakan sebagai panduan penyusunan Software Requirements Specification (SRS) dan Software Architecture Document (SAD))*.
5. **Laravel Web Documentation.** (2026). *Laravel Documentation - Query Builder & Eloquent ORM*. Diakses dari [https://laravel.com/docs](https://laravel.com/docs) *(Digunakan sebagai acuan optimasi query `latestForUnit` dan penanganan versioning berkas)*.
6. **Pressman, R. S., & Maxim, B. R.** (2020). *Software Engineering: A Practitioner's Approach (9th Edition)*. New York: McGraw-Hill Education. *(Digunakan sebagai referensi pengembangan siklus hidup perangkat lunak (SDLC) dan perancangan use case)*.
7. **Sutabri, T.** (2012). *Analisis Sistem Informasi*. Yogyakarta: Penerbit Andi. *(Digunakan sebagai landasan teori perancangan alur proses bisnis dan sistem informasi manajemen)*.
8. **Budi Raharjo.** (2018). *Kumpulan Kueri MySQL dan Implementasinya dalam Framework PHP*. Bandung: Informatika. *(Digunakan sebagai referensi penyusunan rancangan skema basis data relasional)*.
